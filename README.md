# Fern 🌿

**Um espaço para pensar, escrever e conectar ideias.**

O Fern é um aplicativo desktop para reunir anotações, quadros visuais, tarefas, calendário e arquivos em um só lugar. O projeto combina a liberdade de um quadro de ideias com a organização de um sistema de notas conectadas.

## Recursos

- Notas com Markdown, links entre páginas e visualização em grafo.
- Quadros visuais com cartões, conexões, desenhos e notas vinculadas.
- Tarefas, lembretes e calendário.
- Leitura de PDFs e imagens com anotações.
- Busca rápida, atalhos de teclado e diferentes temas.
- Backup local, exportação e importação de conteúdo.

## Executar localmente

Instale [Node.js](https://nodejs.org/) e abra o terminal na pasta do projeto:

```bash
npm install
npm start
```

## Gerar instalador para Windows

```bash
npm run dist
```

A configuração de build utiliza Electron Builder e o ícone personalizado `icon.ico`.

## Tecnologias

JavaScript, HTML, CSS e Electron.
